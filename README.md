# CHEESE-EYES

🧀 CHEESE EYES 
-naver whale: v1.1.0
-chrome: v1.0.0

라이브 방송을 한 화면에서 동시에 감상하고 편리하게 관리할 수 있는 멀티뷰 유틸리티 확장 프로그램입니다.
(치지직 CHZZK / 숲 SOOP 지원)

※ 본 확장 프로그램은 치지직(CHZZK)·네이버(NAVER), 그리고 숲(SOOP)·AfreecaTV와 무관한 비공식 서드파티 도구입니다.

# 📌 주요 기능

## 멀티뷰 화면 구성 (Grid & Main-Sub Layout)
- 1채널부터 다중 채널까지 그리드 배치를 지원합니다.
- 메인 화면과 서브 화면을 나누어 시청할 수 있는 메인-서브 모드를 제공합니다.
- 드래그 앤 드롭으로 채널 순서 및 화면 위치를 간편하게 변경할 수 있습니다.

## 치지직 + 숲(SOOP) 통합 지원
- 하나의 대시보드에서 치지직과 숲(SOOP) 채널을 함께 그리드/메인-서브로 시청할 수 있습니다.
- 채널명, 채널 해시, 태그 검색으로 두 플랫폼의 라이브 방송을 모두 추가할 수 있습니다.
- 치지직과 숲(SOOP) 채널을 그리드 / 메인-서브 레이아웃에서 자유롭게 섞어서 배치할 수 있습니다.
- 숲(SOOP) 로그인 상태를 다중 화면에서도 안정적으로 유지하기 위한 로그인 동기화 기능을 제공합니다. (설정에서 로그아웃 시 관련 쿠키는 즉시 삭제됩니다)

## 채널 추가
- 채널명 또는 채널 해시로 라이브 방송을 추가할 수 있습니다.
- 연관 검색어로 원하는 채널을 더 빠르게 추가할 수 있습니다.
- 스페이스바로 자동완성 선택을 지원합니다.
- 채널명/태그 입력 시 뜨는 연관 검색어 목록에 채널별 실시간 방송 상태를 점 색상으로 표시합니다. (빨간 점: 방송 중 / 회색 점: 방송 종료)
- 라이브 중인 방송만 채널 추가할 수 있습니다.

## 채팅
- 치지직/숲(SOOP) 로그인 상태에서 각 플랫폼 방송 채팅에 참여할 수 있습니다. (치지직, 숲(SOOP) 플랫폼 프로그램 설치 시 고화질 시청도 가능합니다)
- 시청/후원 등에 따라 적립되는 포인트도 실제 각 플랫폼 계정 기준으로 정상 적립됩니다.
  (치지직의 경우 메인 채널만 통나무 포인트 적립이 되는것으로 확인 되었습니다.)
- 각 채팅 탭 옆에 새로고침 버튼이 있어, 특정 채널의 채팅만 골라서 다시 불러올 수 있습니다. 채팅이 늦게 뜨거나 멈췄을 때 전체 화면을 새로고침하지 않고 해당 탭만 빠르게 복구할 수 있습니다.

## 태그 검색
- 검색창에 하나 또는 여러 태그를 입력해 태그 목록을 불러온 뒤 원하는 채널을 선택해 추가할 수 있습니다.
- 클릭 / 드래그 / 클릭, Shift+클릭으로 불러온 채널을 활성화·비활성화할 수 있습니다.
- 치지직·숲(SOOP) 채널 모두 동일하게 태그 검색 기능을 사용할 수 있습니다.

## 팔로우 목록
- 치지직/숲(SOOP) 로그인 시 내 팔로우 목록을 불러와 클릭 한 번으로 빠르게 추가할 수 있습니다.

## 프리셋(Preset)
- 현재 추가된 채널 조합(치지직/숲 혼합 가능)을 프리셋으로 저장해 언제든 한 번에 불러올 수 있습니다.

## ⌨️ 단축키
- `Z` : 그리드 모드로 전환
- `X` : 메인-서브 모드로 전환
- `V` : 설정 창 열기
- `C` : 채팅창 열기/닫기
- `/` : 채널 검색창 빠르게 열기 (검색창 포커스 중 Esc로 닫기)
- `Ctrl(⌘) + ← / →` : 채팅 탭을 이전/다음 채널로 전환 (검색창에 포커스된 상태에서는 전체/치지직/숲(SOOP) 검색 탭 전환)
- `Ctrl(⌘) + ↑` : 현재 보고 있는 채팅 탭 새로고침

## ⚠️ 이용 안내 및 주의사항
- 치지직 채널 삭제 시 안내: 첫번째로 추가된 치지직 채널 삭제 시 화면 레이아웃 및 방송 세션을 안정적으로 재구성하기 위해 플레이어가 자동으로 전체 새로고침됩니다.
- 채널 삭제 후 소리가 나오지 않는 경우: 브라우저의 자동 재생 정책(Autoplay Policy) 또는 스트리밍 세션 재설정으로 인해 간혹 전체 채널이 음소거되거나 영상이 멈추는 경우가 있습니다. 이 경우 상단 새로고침(or F5)버튼을 누르면 정상 동작합니다.
- 숲(SOOP) 채널을 iframe 안에서도 정상적으로 로그인된 상태로 표시하기 위해, 확장 프로그램은 브라우저에 저장된 숲(SOOP) 로그인 쿠키(AuthTicket, UserTicket, sck_session_key, RDB)를 읽어 동일한 값을 파티션 쿠키로 동기화합니다. 이 동작은 로그인 상태 인식 및 채팅·고화질 영상 정상 표시를 위한 것으로, 브라우저 내부에서만 처리되며 외부 서버로 전송되지 않습니다.

## 🔒 개인정보 및 보안
- CHEESE EYES는 자체 서버를 운영하지 않으며, 사용자의 개인 식별 정보나 계정 정보를 수집·저장하지 않습니다.
- 치지직 로그인 세션은 오직 치지직(Naver) 자체 서버와의 통신에만 사용되며, 그 외 어떤 서버로도 전송되지 않습니다.
- 숲(SOOP) 로그인 쿠키는 iframe 내 로그인 상태 유지 목적으로만 브라우저 로컬(chrome.cookies API)에서 처리되며, 마찬가지로 외부 서버로 전송되지 않습니다. 설정에서 로그아웃하면 관련 쿠키가 즉시 삭제됩니다.
- 채널 목록, 레이아웃, 프리셋 등 설정 데이터는 사용자의 브라우저(로컬 저장소)에만 저장됩니다.
